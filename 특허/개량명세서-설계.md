# 개량발명 명세서 설계 — 이동형 플랫폼 기반 저조도 광역 능동탐지

작성일: 2026-07-14
기반: rescue-pose 원발명(`특허명세서.hwpx`, slim 9항) 개량
출원형태: **개량발명 독립 신규 명세서** (원발명은 배경기술로 자기인용, 원 청구항 복사 안 함)

---

## 1. 발명 본질

저조도·광역 재난환경(터널·야간·연기·정전)을 **이동형 플랫폼(드론)이 수색하며, RGB+IR 융합 AI가 구조필요자를 능동 발견·판정**한다.

원발명의 저조도 강점을 **"감시(surveillance)"에서 "수색 발견율(search)"로 전환**하는 것이 발명의 무게중심이다. 드론과 영상 전역운동 보상은 이를 성립시키는 조연이며, 주인공은 "AI가 구조필요자를 찾아낸다"는 탐지 지능이다.

### 개량 필연성 (원발명 고정형으로 안 되는 이유)
- 고정 카메라 = 설치 시야만 감시 → 사각지대 조난자를 못 찾음
- 광역 재난현장(붕괴 터널·넓은 야간지역)에 카메라 무한설치 불가 → 이동 수색 필수
- 이동 + 저조도에서 사람 찾기 = RGB 무력(대비 소실) → **IR 융합 능동탐지가 유일 해법**

---

## 2. 코어 발명포인트 (탐지 지능 = 주인공)

1. **저조도 능동탐지** — 이동 중 RGB+IR 융합맵→포즈로 사람 검출. RGB 신호소실 구간에서 **IR 열원 주도**로 탐지 유지 → 발견율 확보. 원발명 soft 융합의 역할이 "감시 판정"에서 **"탐지 발견 자체"**로 확장된다(융합게이트가 저조도에서 IR 가중을 높여 사람을 놓치지 않고 찾아냄).
2. **광역 수색 커버리지** — 이동으로 사각 없이 훑어 미탐 최소화.
3. **발견 → 구조필요 판정** — 원발명 눕기지속정지 엔진 재활용.

### 진보성 crux (드론에 그냥 얹은 게 아님)
이동 + 저조도 = **이중 열화**. 진보성은 이를 성립시키는 해결에 있다.
- 이동 중 RGB는 저조도 + 모션블러 이중 열화 → 융합게이트가 **조도 + 모션 동시 적응**, IR 주도로 탐지율 방어
- 이동으로 카메라가 움직여 정지판정이 깨짐 → **영상 전역운동 보상**으로 대상 고유 이동량만 산출(뒷받침)

---

## 3. 구성부 (탐지 무게중심)

| 역할 | 구성 |
|------|------|
| **탐지엔진 (핵심)** | 원발명 융합신경망(130)·키포인트 디코더(140)·자세분류(150)·구조판단(160) |
| **탐지 열쇠** | 조도(+모션)적응 융합게이트(134′) — 저조도에서 IR 가중↑ = 발견율의 심장 |
| 이동 캐리어 (조연) | 드론 기체(200) · RGB+IR 시리얼 페이로드 인터페이스(220) |
| 이동 성립 (뒷받침) | 영상 전역운동 보상부(250) · 판정신뢰 게이트(260) |
| 결과 | 발견위치 보고부(270) · 경보·통신부(180) |

### 영상 전역운동 보상 (구 "에고모션 보상")
- 문제: 드론 이동으로 카메라가 움직임 → 지면에 정지한 사람도 화면상 위치가 밀림 → 원발명 정지조건(프레임 간 키포인트 이동량 ≤ 임계)이 깨짐
- 해결: 카메라 움직임이 유발한 화면상 전역운동을 추정·제거하여 **대상의 고유 이동량**만으로 정지판정
- 추정 실시예: (a) 관성센서(IMU) 기반 호모그래피 워핑, (b) 배경 특징점 광류 기반 전역운동 차감, (c) IMU 초기워프 + 광류 잔차보정(주추천)
- **명세서 용어 규칙: "에고모션" 대신 "플랫폼 이동에 의한 영상 전역운동 보상" 등 우리말로 기술**

## 6. 명세서 작성 시 주의

- **에고모션 용어 우리말화** — "플랫폼 이동에 의한 영상 전역운동 보상"
- **원 청구항 복사 금지** — 원발명은 배경기술 인용, 청구항은 전부 새 발명
- **무게중심 유지** — 서술은 "AI 저조도 능동탐지"가 주인공, 드론·전역운동보상은 조연
- **진보성 방어** — SAR드론+열화상 공지 다수 → "융합맵→포즈 브릿지(원발명 신규성) + 이동 저조도 발견용 융합 역할확장 + 이중열화 해결"로 조합 진보성 논증
- **원발명 게이트 미결 승계** — 정식 KIPRIS/Espacenet 서치, Doc3 in-bed 전문입수는 변리사 몫(원발명 게이트에서 이월)
